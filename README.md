## 🧠 About Me

I am a **Backend Engineer** based in Kolhapur, Maharashtra, India, with over 3 years of experience designing and building scalable, reliable backend systems using Node.js, Express.js, and SQL/NoSQL databases.

I specialize in system design, API architecture, and writing clean, maintainable code with unit and integration test coverage. I have owned a reseller SaaS platform end to end, optimizing database queries to cut API response times by ~60%. 

- 🔭 Currently working at **Bluebash** as an Associate Software Developer.
- 🌱 Deepening expertise in **Microservices, Distributed Systems, and System Architecture**.
- 🎯 Focused on shipping **production-grade APIs** and cloud infrastructure.
